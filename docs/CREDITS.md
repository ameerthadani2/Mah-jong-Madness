# Credits and audio assets

## Audio

Every sound the app plays is listed in `apps/mobile/assets/audio/manifest.json`. The app never names a file
directly: it asks for a cue id (`sfx.discard`, `voice.mandarin.pong`, …) and plays whatever file the
manifest gives for it.

### What ships today

All files under `apps/mobile/assets/audio/` are **synthesised placeholders** made by
`apps/mobile/scripts/gen-audio.cjs` (sine tones and filtered noise, mono 16-bit WAV at 16 kHz, each under
20 KB). They are ours, carry no third-party rights and exist only so the app is audible during development
and QA. The "voice" placeholders are short musical motifs, not speech. No Taiwanese voice set is bundled:
with the Taiwanese voice selected, calls appear as banners only.

|---|---|---|
| `sfx.draw` | `sfx/draw.wav` | you draw from the wall |
| `sfx.discard` | `sfx/discard.wav` | any discard lands in a pond (the clack) |
| `sfx.drawGame` | `sfx/draw-game.wav` | 流局: the wall ran out with no winner |
| `sfx.fanfare` | `sfx/fanfare.wav` | you won the hand |
| `sfx.tick` | `sfx/tick.wav` | each of the last 5 seconds of your turn |
| `sfx.tap` | `sfx/tap.wav` | picking a tile, pressing a claim button |
| `voice.<set>.chi` | `voice/<set>/chi.wav` | any seat calls 吃 |
| `voice.<set>.pong` | `voice/<set>/pong.wav` | any seat calls 碰 |
| `voice.<set>.kong` | `voice/<set>/kong.wav` | any seat calls 槓 (exposed, concealed or added) |
| `voice.<set>.hu` | `voice/<set>/hu.wav` | a win off a discard (胡) |
| `voice.<set>.selfdraw` | `voice/<set>/selfdraw.wav` | a self-drawn win (自摸) |

`<set>` is `mandarin` or `taiwanese`, matching the player's choice in Settings → Sound.

### Replacing the placeholders with commissioned audio

1. Deliver each recording at the path in the table (WAV, or change the extension in the manifest to
   `.m4a`/`.mp3`), mono, trimmed tight (voice calls under 0.6 s feel snappy), normalised to about -3 dBFS.
   Keep each file under the manifest's `maxBytes` (20 KB) or raise that limit deliberately.
2. In `manifest.json`, set that cue's `"placeholder": false` so the generator never overwrites it, and
   adjust `"volume"` (0–1) to balance it against the others.
3. Run `node scripts/gen-audio.cjs` from `apps/mobile`. It regenerates the remaining placeholders and
   rewrites `src/audio/sources.ts`, the table of static `require()` calls the bundler needs. A cue whose file
   is missing is simply left out, so the app stays silent for it instead of failing to build.
4. Run `npm test` (the manifest test checks every file, size and require line) and add the recording's
   credit below.

The Taiwanese entries are already in the manifest with `"placeholder": false`; dropping the five files in
`voice/taiwanese/` and running step 3 turns the Taiwanese voice on.

## Fonts and art

Fonts come from Google Fonts via `@expo-google-fonts/*` (SIL Open Font Licence). Tile faces and
icons are drawn in code (`apps/mobile/src/components`); the avatar artwork under `apps/mobile/assets/avatars` is imported by `scripts/import-avatars.cjs` (record its source here).
